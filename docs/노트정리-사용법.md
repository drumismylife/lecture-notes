# 강의 아카이브 · 노트 정리 사용 설명서

이 문서는 **lecture-notes 강의 아카이브**(drumismylife.github.io/lecture-notes)에 강의노트를
만들고 올리는 전체 방법을 설명합니다. 핵심은 Claude Code의 **`lecture-note-builder` 스킬**이
강의자료 + 녹취로 노트 HTML을 만들고 배포하는 것입니다.

---

## 0. 한눈에 보는 흐름

```
강의 녹취/자료 준비
   │
   ├─[폴더 모드]  prepare.py 로 녹취 정리 → 녹취/·강의자료/ 폴더에 둠
   └─[붙여넣기]   아이폰 등에서 복사한 녹취를 대화창에 직접 붙여넣음
   │
   ▼
Claude Code에서 "○○ N주차 노트 정리해줘"  ← lecture-note-builder 스킬
   │   · 과목 프로필(학업계획서·테마·노트 스타일) 로드
   │   · 자료근거 / 교수강조 / 보충 3출처로 정리 + 검증
   ▼
노트 HTML 생성 → output/<과목>/weekNN.html 저장
   │
   ▼
deploy.py 가 data.js 등록 + 뒤로가기 버튼 주입 + git push
   │
   ▼
GitHub Pages 자동 빌드 (~90초) → 사이트에 반영
```

---

## 1. 노트 만들기 — 두 가지 입력 모드

### 모드 A. 폴더 모드 (파일이 있을 때)
1. 수업 후 녹취 파일이 있으면 `python3 scripts/prepare.py` 실행 — RTF→txt 변환, 과목 자동 감지,
   `1학기/<과목>/녹취/`로 이동.
2. 강의자료(슬라이드·PDF 등)는 `1학기/<과목>/강의자료/`에 둡니다.
3. Claude Code에서 요청:
   > "헬라어 3주차 노트 정리해줘"
4. 스킬이 해당 폴더의 녹취·강의자료를 읽어 노트를 생성합니다.

### 모드 B. 붙여넣기 모드 (파일 없이 — 아이폰에서 복사한 경우)
아이폰 등에서 녹취 스크립트를 **복사해 대화창에 그대로 붙여넣고** 요청하면 됩니다. 파일이 필요 없습니다.
> (녹취 텍스트 붙여넣기)
> "위 녹취로 신약 11주차 노트 만들어줘. 강의자료는 없어."

- 강의자료도 채팅에 붙여넣거나 첨부할 수 있습니다.
- 자료가 부족하면 스킬은 **임의로 지어내지 않고** "이 부분은 자료에 없습니다"라고 표시합니다.

## 2. 내용 검증 — 노트를 신뢰하는 법

모든 노트는 내용을 **3가지 출처로 구분**해 표시하고, 작성 전에 검증을 거칩니다.

| 표시 | 의미 | 어떻게 읽나 |
|------|------|------------|
| (본문) | **자료근거** — 녹취·강의자료에 실제로 있는 내용 | 강의에서 직접 나온 것 |
| ⭐ 교수 강조 / 시험 | **교수 강조** — 반복·강조·시험 언급 | 시험 대비 우선순위 |
| 🔎 보충 | **보충정리** — 자료에 없어 검색·관련 스킬로 보완 | 참고용, 강의 내용과 구분 |

- 노트 **맨 아래 "출처·검증 요약"** 에 자료근거 N · 교수강조 N · 보충 N · 미확인 항목이 정리됩니다.
- 보충은 과목별 관련 스킬(예: 헬라어→메이첸 문법, 신약/교회사→성경사전·역사배경)로 교차검증됩니다.
- **할루시네이션 0 원칙** — 강의에 없는 사실은 만들지 않습니다.

## 3. 노트 음성 듣기 (운전 중 청취) — 요청 시에만

운전·이동 중 노트를 들으려면 **명시적으로 요청**하세요. (매번 자동 생성하지 않음 — 사용량 절약)
> "방금 만든 신약 11주차 노트, 음성으로 만들어줘"

- 노트를 듣기 좋은 낭독 스크립트로 정리한 뒤, **로컬 음성(macOS `say`, 한국어 Yuna)** 으로 MP3를
  만들어 사이트 오디오 플레이어의 **"주차별 노트 낭독"** 에 추가합니다.
- MP3 재생은 잠금화면·블루투스·카플레이에서 백그라운드로 됩니다(팟캐스트처럼).
- 비용: 낭독 스크립트 작성에 노트 1편당 대략 **+5천~1.5만 토큰**이 **Pro 주간 사용량에서 차감**
  (별도 달러 청구 아님). MP3 인코딩 자체는 사용량 0.
- macOS에 한국어 음성이 없으면: 시스템 설정 > 손쉬운 사용 > 음성 콘텐츠에서 **Yuna** 추가.

## 4. 새 학기 / 과목 추가하기

데이터 기반 구조라 **코드 수정 없이** 추가됩니다.

1. **`data.js`** `semesters[]`에서 해당 학기의 `courses`에 과목을 추가하거나, 빈 학기(2학기·계절학기)에
   과목을 채웁니다. 각 과목은 `meta`(코드·제목·영문·강조색 acc·설명)와 `weeks[]`를 가집니다.
   - 주차 골격은 과목 `profiles/<키>/syllabus.md`의 주차계획에서 스킬이 자동 생성할 수 있습니다.
2. **`scripts/config.json`** `subjects`에 과목 항목 추가(`output_folder`·`semester_folder`·
   `semester`·`course_key`·`profile`·`related_skills`·`keywords`). `semesters`에 학기도 등록.
3. **`profiles/<키>/`** 에 `profile.md`(과목 특징)·`syllabus.md`(학업계획서)·`theme.json`(디자인)을 둡니다.
   기존 5과목(greek/min/phil/nt/hist)을 참고하세요.
4. 활성 학기를 바꾸려면 `data.js`에서 해당 학기 `active: true`(나머지 false), `config.json`의
   `active_semester`도 맞춥니다.

> 비활성 학기 노트는 `output/<학기id>/<과목>/weekNN.html`로 네임스페이스됩니다. 활성 학기는
> 기존처럼 `output/<과목>/weekNN.html`.

## 5. 배포 & 문제 해결

### 배포
- 스킬이 노트를 만든 뒤 자동으로, 또는 수동으로:
  ```bash
  python3 scripts/deploy.py 헬라어 03            # 활성 학기, 오늘 날짜
  python3 scripts/deploy.py 기독교철학 07 2026.04.16
  python3 scripts/deploy.py 헬라어 03b           # 같은 주차 추가 자료
  python3 scripts/deploy.py 헬라어 03 --semester 2026-2   # 다른 학기
  ```
- 배포 후 GitHub Pages 빌드에 **약 90초** 걸립니다.

### 문제 해결
- **새 노트가 404** → 빌드 지연(90초 대기 후 재확인). 그래도 404면 파일 경로/대소문자 확인.
  ```bash
  curl -s -o /dev/null -w "%{http_code}\n" "https://drumismylife.github.io/lecture-notes/output/greek/week03.html"
  ```
- **사이트에 변경이 안 보임(캐시)** → `index.html`의 `data.js?v=YYYYMMDD…` 버전을 올리면 강제 갱신.
- **한글 파일명 404(NFD/NFC)** → macOS 한글 파일명은 NFD라 URL 인코딩이 어긋날 수 있음.
  **신규 노트 파일명은 ASCII(weekNN)로 고정**하고 한글은 제목에만 쓰세요. deploy/update_data는
  경로를 NFC로 정규화합니다.
- **data.js 깨짐 우려** → deploy/update_data는 대상 **학기 span 안에서만** 수정하므로 다른 학기·과목을
  건드리지 않습니다. 수정 후 `node -e` 로 파싱 확인 가능.

## 6. 관련 파일 지도
- `index.html` — 사이트(완전 데이터 기반 렌더: 학기 전환·과목·주차·도구·오디오).
- `data.js` — 모든 학기·과목·주차·도구·오디오 데이터.
- `scripts/config.json` — 학기·과목·폴더·프로필·관련스킬 **단일 설정 원천**.
- `scripts/prepare.py` / `watch.py` / `deploy.py` / `update_data.py` — 녹취 준비·감시·배포 파이프라인.
- `profiles/<키>/` — 과목별 학업계획서·노트 스타일·디자인 테마.
- `~/.claude/skills/lecture-note-builder/SKILL.md` — 노트 정리 스킬(Claude Code 전역).
