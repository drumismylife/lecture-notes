01학습목표
  • 미래시제의 시상접미사 σ를 식별하고, 부정과거와의 형태적 차이를 구별한다
  • 능동·중간·수동 미래 활용형을 변화시킬 수 있다
  • Stanley Porter의 동사상 이론에서 미래 = 기대적 측면(현재성 0)임을 이해한다
  • 자음+σ 결합 변화 규칙(ψ, ξ)을 적용하여 미래형을 만든다
  • εἰμί, 단축동사, 유음동사, μι-동사의 불규칙 미래형을 익힌다
02복습 연결

부정과거 → 미래 연결 포인트

  • 부정과거: 접두표식 ε-(augment) + 시상접미사 σ + 2차어미(-α, -ας, -ε(ν)…)
  • 미래: augment 없음 + 시상접미사 σ + 1차어미(-ω, -εις, -ει…)
  • 핵심 차이: 미래는 앞에 ε-가 없고, 어미가 현재와 동일

04미래시제 형태론

핵심 공식 ⭐ 시험

  • 능동 미래: 어간 + σ + 1차 능동 어미 → λύσω (나는 풀 것이다)
  • 중간 미래: 어간 + σ + 1차 중간/수동 어미 → λύσομαι (나는 스스로 풀 것이다)
  • 수동 미래: 어간 + θησ + 1차 중간/수동 어미 → λυθήσομαι (나는 풀릴 것이다)

부정과거와의 차이: 부정과거는 앞에 ε-(augment) + 뒤에 σα, 미래는 augment 없이 σ만

자음 + σ 결합 변화 (p.149) ⭐ 시험

순음 (입술)치음 (혀)후음 (목)
π / β / φ + σ → ψ τ / δ / θ + σ → σ κ / γ / χ + σ → ξ

  • γράφω → γράψω
  • λαμβάνω → λήμψομαι
  • βλέπω → ὄψομαι
  • πείθω → πείσω

05동사상(Verbal Aspect) 함의

Stanley Porter: 미래 = 기대적 측면

미래시제는 단순히 앞으로 올 시간뿐 아니라 "현재의 기대(expectation)"의 측면을 담당한다.

08특수동사의 미래

εἰμί의 미래 ⭐ 시험

형태: ε + σ + 중간수동 어미 (-ομαι 계열)

단수복수
1인칭ἔσομαιἐσόμεθα
2인칭ἔσῃἔσεσθε
3인칭ἔσταιἔσονται
  • ἔσεσθε υἱοί = "너희는 아들들이 될 것이다"
  • φωτεινὸν … ἔσται = "밝게 될 것이다"

불규칙 동사: γίνομαι

  • 미래: γενήσομαι (현재와 미래 어간이 매우 다름!)
  • 미래/부정과거에 원형적 어근 γεν-이 더 잘 보존됨
  • 부정과거: ἐγενόμην
  • 예문 (p.150): γενήσεται πηγή = "그것은 근원이 될 것이다"

단축동사(Contract Verbs)의 미래

  • τιμάω → τιμήσω (α → η before σ)
  • ζάω → ζήσω / ζήσομαι, ζήσεσθε

예문: 요한복음 14:19 ⭐ 교수강조

ζῶ … ζήσεσθε = "나는 살아있다(현재성 2), 너희도 살 것이다(현재성 0)"

  • ζῶ: ζάω 직설법 현재 능동태 1인칭 단수 [현재성 2]
  • ζήσεσθε: ζάω 직설법 미래 능동태 2인칭 복수 [현재성 0]

유음동사(Liquid Verbs)의 미래

σ 탈락 + ε 첨가 + 단축 → circumflex 악센트

  • μένω → μενῶ (미래)
  • κρίνω → κρινῶ / κρινοῦμαι (미래 중간수동)
  • αἴρω → ἀρῶ (이중모음 αι 수축)

μι-동사의 미래

  • δίδωμι → 능동: δώσω / 수동: δοθήσομαι
  • δι- 탈락, δω- 남음 + σω

기타 예문

  • πέμψω τὸν υἱόν μου = "나는 나의 아들을 보낼 것이다" (πέμπω 미래 능동 1단)
  • λήμψεται τὸν στέφανον τῆς ζωῆς = "그는 생명의 면류관을 받을 것이다" (λαμβάνω 미래 중간 3단, 야고보서 1:10)
  • προελεύσεται πρὸ αὐτοῦ = "그는 그의 앞에 먼저 올 것이다" (προέρχομαι 미래 디포넌트 3단)
