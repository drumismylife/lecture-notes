시험 형식 (근거: 교수 카톡 공지 2026.7.3 백업 · 7주차 강의)
100% LMS 오픈북. 유형: ① 동사 분해 ② 문장 전체 해석 ③ 개념 서술형. 범위는 11과~20과 누적 — "수업에서 다룬 모든 연습문제와 강조 예문 전부"가 출제 대상.
① 정형동사(직설법·명령법) 분해 — 7요소
원형(한글 음가) + 법·시제·태·인칭·수·(현저성/현재성) — 교수 답안 표기법.
예시 형태모범 답안
ἀκούσει"아쿠오"(ἀκούω)의 직 · 미 · 능 · 3 · 단 (0)
πεπίστευκεν"피스튜오"(πιστεύω)의 직 · 현완 · 능 · 3 · 단 (3)
ποίησον"포이에오"(ποιέω)의 명 · 1부과 · 능 · 2 · 단 (0)
⭐ 감점 주의: 마지막에 뜻(한국어/영어)을 반드시 함께 쓸 것 — "마지막에 [뜻] 쓰는 것을 절대로 잊지 말아야 한다"(3주차 강의, 중간고사 때도 동일).
⭐ 채점 배점(9강 육성): 원형(과 현재성) 표기 = 0.2점, 법·시제·태·인칭·수 각 요소 0.1점씩, 현재성 표기 별도 0.2점 — "현재성은 0.2점이에요. 안 쓰시면 안 돼. 꼭 써주세요, 맨 마지막에 괄호 하고." 요소 하나하나가 감점 대상이므로 빈칸 금지(무엇이든 써서 부분점수라도 확보).
② 분사 분해 — 인칭 대신 성·수·격 + 용법
원형의 분(사) + 시제 + 태 + 성·수·격 + 용법 — 정답지 표기 그대로.

핵심 개념동사상(Verbal Aspect)과 현재성(Prominence) — 이 과목의 심장
상(aspect)이란?
시제(tense)가 "언제 일어났나"라면, 상(aspect)은 화자가 그 사건을 어떻게 그려서 보여주는가이다. 헬라어 동사의 시제 선택은 시간 정보보다 상의 선택이며, 이것이 본문 해석의 열쇠가 된다(교재의 언어학적 틀 — Ellis, "Aspect–Prominence" 참조, 교재 p.159 각주).
상 3분 체계 × 시제 매핑 (교재 p.159·167 표)

미래시제0사건을 총괄적으로 — "~할 것이다"
상태상
(결과·상태)		현재완료시제3결과 상태의 지속 — "~해 있다/~한 상태다"
과거완료시제3과거 기준과거 시점의 결과 상태 — "~해 있었다"
⭐ 답안 규칙: 모든 동사 분해 끝에 현재성 점수를 표기 — 부정과거·미래 = 0("미래는 부정과거와 같이 현저성 0", 교수 공지), 미완료 = 1, 현재 = 2, 완료 = 3. 이 점수는 담화에서 얼마나 도드라지는가(전경성)의 척도: 0 = 배경 서술, 3 = 최전방 강조.

과거완료 — 구조만 정확히 (교재 p.159 분해표 기준)
접두모음 ε + 자음중복 + 어간 + κ + -ειν 계열 어미: ἐλελύκειν(1단) — 신약 출현 빈도는 낮고, 연습문제에서는 ᾔδειν(οἶδα)과 ἐληλύθει(ἔρχομαι, 19과 문장 3)로 등장.
🔎 보충(메이첸 교차검증): 과거완료 능동 전체 어미 줄 -ειν, -εις, -ει, -ειμεν, -ειτε, -εισαν — 교재 16과 본문 변화표(pp.161~166)와 대조 권장(본 노트는 μι동사 δίδωμι 과거완료 표 p.168로 부분 확인).
17~19과분사 3종 총람 — 현재·부정과거·완료(+미래) (pp.170~196)
분사의 3용법 + 상대시간
① 독립적: 관사+분사 = 실명사("~하는 자") ② 관형적: 명사 수식(수식 명사의 성·수·격에 일치) ③ 부사적: 시간·이유·조건·양보·목적(문맥 판단). 시제는 주동사와의 상대시간: 현재 분사 = 동시("~하면서"), 부정과거 분사 = 선행("~한 후"), 완료 분사 = 결과 상태("~해 있는 채"), 미래 분사 = 목적("~하러"). 분사의 부정은 μή.

서술형 대비개념 서술형 예상 문답 (교수 공지: 기말부터 개념 문제 도입)
Q1.헬라어 동사의 시제와 동사상(aspect)의 관계를 설명하라.
헬라어 동사의 시제는 사건의 시간 위치보다 화자가 사건을 그리는 방식(상)을 우선 표현한다. 미완료상(현재·미완료과거)은 진행·반복으로, 완료상(부정과거·미래)은 총괄적 한 덩어리로, 상태상(현재완료·과거완료)은 결과 상태의 지속으로 사건을 그린다. 따라서 같은 사건도 κρίνεται(진행)와 κέκριται(확정된 상태)는 해석이 달라진다(요 3:18).
Q2.현재성(현저성) 점수 체계를 쓰고 각 값의 담화 기능을 설명하라.
부정과거·미래 = 0, 미완료 = 1, 현재 = 2, 완료 = 3. 점수가 낮을수록 배경 서술(부정과거는 이야기의 뼈대), 높을수록 담화의 전면에 도드라진다(완료는 화자가 가장 강조하는 상태·결과 정보). 답안의 동사 분해 끝에 (0)~(3)으로 표기한다.
Q3.현재완료의 형태 구성 요소를 λέλυκα를 예로 분해하라.
λέλυκα = λ(첫 자음 중복) + ε(중복 모음) + λυ(어간) + κ(상태상 시상접미어) + α(능동 1인칭 단수 어미)(교재 p.159·160). 모음 시작 어간은 자음중복 대신 어두 모음 장음화(ἐλπίζω→ἤλπικα), 수동은 κ 없이 어간+μαι(λέλυμαι), 제2완료는 κ 없이 α만 붙는다(γέγονα).
Q4.분사의 세 가지 용법을 예문과 함께 설명하라.
① 독립적 — 관사+분사가 명사처럼: ὁ πιστεύων "믿는 자"(요 3:18). ② 관형적 — 명사를 수식하며 성·수·격 일치: πνεύματι ἁγίῳ ἀποσταλέντι "보냄받은 성령으로"(벧전 1:12). ③ 부사적 — 주동사를 시간·이유·조건·양보·목적으로 수식: ἀναβλέψας … ἐστέναξεν "우러러본 후 탄식하셨다"(막 7:34). 부사적 의미는 문맥이 결정한다.
Q5.현재 분사와 부정과거 분사의 시간 관계 차이를 설명하라.
분사의 시제는 절대 시간이 아니라 주동사에 대한 상대시간이다. 현재 분사는 주동사와 동시("~하면서": Ἐσθιόντων αὐτῶν "그들이 먹을 때"), 부정과거 분사는 주동사보다 선행("~한 후": λαβὼν … ἔφαγεν "취한 후 드셨다")(마 26:26). 완료 분사는 결과 상태 지속, 미래 분사는 목적("~하러")을 나타낸다.
Q6.속격 독립 구문(genitive absolute)이란 무엇인가?
분사의 의미상 주어가 주동사의 주어와 다를 때, 분사와 그 주어를 모두 속격으로 두는 부사적 구문. 예: Ἐσθιόντων αὐτῶν(그들이 먹을 때 — 주동사 주어는 예수, 마 26:26), γενομένης διωγμοῦ(박해가 발생한 후 — 주동사 주어는 "그 사람", 마 13:21). 분해 시 격을 "속"으로 쓰고 부사적 용법(주로 시간)을 명기한다.
Q7.현재 명령과 부정과거 명령의 차이를 상의 관점에서 설명하라.
현재 명령은 미완료상 — "계속·반복해서 하라"(γίνου "계속 본이 되라", 딤전 4:12). 부정과거 명령은 완료상 — 행위 자체를 단회·총괄적으로 이루라(Ποίησον τοῦτο "이것을 하라", 눅 7:8). 금지 μή + 현재 명령은 "이미 하고 있는 것을 중단하라"(μὴ φοβεῖσθε — 이미 두려워하는 제자들에게, 막 6:50). 주기도문의 간구가 모두 부정과거 명령인 것도 같은 원리다.
Q8.완곡어법(우언법) 완료란 무엇인가?
완료 분사 + εἰμί로 완료 시제를 풀어 쓰는 구문. πεπεισμένος ἐστίν = "확신하고 있다"(눅 20:6), κἂν ᾖ πεποιηκώς(약 5:15 — εἰμί가 가정법일 때). 분사가 상태상을, εἰμί가 법·인칭 정보를 나눠 지는 구조다.
Q9.οἶδα는 왜 특수한가?
형태는 완료이지만 의미는 현재("알고 있다")로 쓰이는 동사. 따라서 과거완료형 ᾔδειν은 의미상 과거("알고 있었다")가 된다(요 1:31 κἀγὼ οὐκ ᾔδειν αὐτόν). 분사도 εἰδώς/εἰδυῖα(행 5:7 μὴ εἰδυῖα "알지 못한 채")로 활발히 쓰인다.
Q10.중성 복수 주어는 왜 단수 동사를 취하는가? (15과 복습 — 기말 누적 범위)
헬라어에서 중성 복수는 집합체 하나로 간주되어 단수 동사를 취한다. 예: αὐτὰ ἐκηρύχθη "그것들이 선포되었다"(벧전 1:12 — 주어 중성 복수 + 동사 3인칭 단수). 분해 문제에서 "왜 단수인가"를 묻는 함정으로 출제될 수 있다.
