동사(3-1) — 직설법 부정과거 능동·중간태

담당 안호준 교수 · 제3강 (교재 11과, 112~121쪽)

핵심동사상(verbal aspect)과 부정과거

⭐ 교수 강조 — 부정과거의 현재성 0

부정과거(아오리스트)는 현재성이 0에 해당하는 디폴트 서술. 0이라고 해서 중요하지 않은 것이 아니라, 가장 기본 바닥을 깔아주기 때문에 미완료(1)·현재(2)·완료(3)의 차이가 빚어진다.

화자가 어떤 정보를 배경(0)으로 두고 무엇을 전면(2~3)에 부각하는지가 해석의 핵심 단서.

  • 전통적 이해: 부정과거 = 과거의 단면, 단순 발생 · 미완료 = 과거의 반복·진행
  • 언어학적 접근: 시간(tense)보다 상(aspect)이 핵심. 부정과거는 현재를 지칭하기도 하므로 단순 '과거'만으로 설명 불충분
  • 편의상 해석: 부정과거 = "~였다/했다", 미완료 = "~하고 있었다/하곤 했다"

⭐ 교수 강조 — 파싱 시 현재성 반드시 표기

파싱 끝에 괄호 안에 현재성 숫자를 반드시 기재. 빠뜨리면 −0.2점 감점. 원형 누락도 −0.2점.

예: ἐξῆλθεν → ἐξέρχομαι, 직설법 부정과거 능동태 3인칭 단수 (0)

11과제1부정과거 능동태 (교재 115쪽)

형성 공식

어두 증가 ἐ- + 어간(불변) + σ(시그마) + α형 어미

핵심 시그널 3가지: ① 앞에 ἐ-(엡실론) = 과거 표시, ② 뒤에 σ(시그마) = 부정과거 표시, ③ 어미가 α(아)형으로 전환

⭐ 교수 강조 — 어미 반복 암기 (10번!)

-σα, -σας, -σε(ν), -σαμεν, -σατε, -σαν

교수님: "사·사스·세·사멘·사테·산 — 10번 반복하세요!"

모음 어간의 어두 증가

  • α + ἐ- → η (장음화)
  • ι + ἐ- → 장 ι
  • ο + ἐ- → ω (장음화)

자음접변 (σ와 어간 말 자음)

  • 양순음 (π, β, φ) + σ → ψ : πέμπω → ἔπεμψα
  • 치음 (τ, δ, θ) + σ → σ : πείθω → ἔπεισα
  • 구개음 (κ, γ, χ) + σ → ξ : ἐπιστρέφω → ἐπέστρεψα 보충
11과제1부정과거 중간태 (교재 115쪽)

⭐ 교수 강조 — 부정과거부터 중간태 ≠ 수동태

현재 시제에서는 "중간·수동태"로 하나였지만, 부정과거부터는 중간태와 수동태가 따로 분리됨. 수동태는 12과(다음 시간)에서 별도 학습.

11과제2부정과거 — 어간이 변하는 부정과거 (교재 117쪽)

제1 vs 제2 부정과거 비교

  • 제1부정과거: 어간 불변 + σ + α형 어미
  • 제2부정과거: 어간이 변함 + σ 없음 + 미완료 어미(-ον, -ες, -ε(ν), -ομεν, -ετε, -ον)
  • 공통: 둘 다 앞에 ἐ-(어두 증가) 공유

⭐ 교수 강조 — 제2부정과거의 어간 변화

λαμβάνω(취하다)의 어간이 λαβ-로 "쪼그라듬" → ἔλαβον. ἔλαβον만 보고 λαμβάνω에서 왔다고 추론하기 매우 어렵다! 개별 암기 필요.

교수님: "이런 원리를 익히고 나면 — 아, ἔλαβον은 λαμβάνω의 제2부정과거 능동태구나! 이렇게까지 어간이 변하는 것이 있구나."

11과이태동사(deponent)와 반이태동사 (교재 120쪽)
  • 이태동사: 현재에서도 이태동사이고 부정과거에서도 이태동사 형태 유지.
  • 예: γίνομαι → 부정과거 ἐγενόμην (여전히 중간태 형태)
  • 반이태동사: 현재에서는 이태동사 형태이지만, 다른 시제에서 능동태로 복귀.
  • 예: ἔρχομαι(현재 이태) → 미완료 ἠρχόμην(이태) → 부정과거 ἦλθον(능동 형태)

"이 문장은 꼭 기억해 주시기 바랍니다. 제가 왜 이렇게 별표를 막 치는지는 여러분이 이해하실 것이다." — 시험 범위.

Καὶ ἐξῆλθεν ὁ Ἰησοῦς καὶ οἱ μαθηταὶ αὐτοῦ εἰς τὰς κώμας Καισαρείας τῆς Φιλίππου· καὶ ἐν τῇ ὁδῷ ἐπηρώτα τοὺς μαθητὰς αὐτοῦ λέγων αὐτοῖς· Τίνα με λέγουσιν οἱ ἄνθρωποι εἶναι;

"나가셨다(배경) → 묻고 계셨다(진행) → 말하고 있다(전면)" — 동사상이 해석의 단서를 제공하는 인상적 사례.

"예수께서 그들에게 명하셨다"

3번 — ἦλθαν 형태 (요 4:27)

ἦλθαν οἱ μαθηταὶ αὐτοῦ

"그의 제자들이 왔다"

  • ἦλθαν ← ἔρχομαι, 직설법 제2부정과거 능동태 3인칭 복수 (0)
  • ἦλθον(표준)과 ἦλθαν(변이형, 신약 5회) — -ον/-αν 혼용 현상. λέγω도 εἶπαν(95회, 3인칭 복수) vs εἶπον(62회, 주로 1인칭 단수)으로 유사. 초기부터 1인칭 단수/3인칭 복수 구분 경향이 있었던 것으로 보임. 교수 강조

4번

ὁ δὲ εἶπεν αὐτοῖς

"그런데 그는 그들에게 말했다"

  • εἶπεν ← λέγω, 직설법 제2부정과거 능동태 3인칭 단수 (0)

자료근거(제3강 영상 자막1·2) · 본문 전반 교수 강조 · 8건 보충 · 1건

· 자료근거: 제3강(교재 11과, 112~121쪽) 영상 자막 2편을 정리. 자막1은 찬양·주기도문 암송(시편 145:1 헬라어, 주기도문 연상 암기법), 자막2는 부정과거 문법+연습문제.

  • 보충: 구개음 자음접변 예시(ἐπιστρέφω → ἐπέστρεψα) — 메이첸 표준 교차검증.
  • 확인 필요: 교재 세부 페이지·일부 예시는 자동자막 특성상 부정확 가능, 교재로 최종 확인 권장.
