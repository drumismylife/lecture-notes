1쪽 요약

  • 영국 성공회 = 헨리 8세의 이혼 문제로 로마와 결별(1532~1534 수장령)한 "영국식 가톨릭". 신학·직제는 가톨릭과 유사하고 수장만 교황→국왕으로 바뀜.
  • 종교를 국가가 규정·운영하는 수단으로 삼은 체제 = 시민 종교(civic religion).
  • 영어 성경 계보: 위클리프 → 틴데일(신약 1526, 1536 화형) → 매튜 성경(1537) → 대 성경 → 킹제임스 흠정역(1611, 틴데일 70% 근거).
  • 왕위 3단계: 에드워드 6세(친개신교) → 메리(친가톨릭, "피의 메리") → 엘리자베스 1세(중간노선, 양쪽에서 비난).
  • 청교도(Puritans) = 성공회를 종교개혁 사상으로 정화(purify)하려던 사람들. 성공회 안에 남아 개혁하려는 쪽 vs 분리해 나가는 분리주의자.
  • 분리주의자 → 네덜란드·신대륙(1620 메이플라워) → 회중교회(하버드·예일 설립) · 침례교(일반 1609 / 특수 1638) · 퀘이커(1647).
  • 대륙에서는 개신교와의 재결합이 결렬(교황권·화체설) → 로욜라와 예수회(1540) → 트렌트 공의회(1545~1563) → 위그노 학살(1572)·30년 전쟁(1618~1648).

Q1. 영국 성공회의 성립 과정과 성격을 서술하시오.
  • 배경: 헨리 8세 — 아들(후계자) 없음, 캐서린과 이혼 → 앤 볼레인과 결혼 원함
  • 과정: 1527 교황에 혼인 무효 요청 → 교황 머뭇거림(캐서린이 찰스 5세의 고모) → 1532 크롬웰, 1533 결혼 무효·앤과 결혼·엘리자베스 출생 → 교황 파문 → 1534 수장령
  • 성격: 로마식이 아닌 영국식 가톨릭. 신학·직제는 가톨릭과 유사, 수장만 국왕. 시민 종교. 이후 에드워드 6세(개신교) → 메리(가톨릭 복귀) → 엘리자베스 1세(중간 노선)
Q2. 청교도와 분리주의자의 차이, 그리고 분리주의자에서 나온 교파를 설명하시오.
  • 청교도 = 성공회를 정화하려는 사람들(안에서 개혁) / 분리주의자 = 성령이 떠났다고 보고 독립교회를 세움
  • 분리주의자 → 신약 연구 → 유아세례 부정 → 침례교(일반 1609, 특수 1638), 회중정체 → 회중교회(메이플라워 1620, 하버드·예일)
Q3. 트렌트 공의회의 배경·결정·영향을 서술하시오.

  • 영향: 유럽 재통합 무산, 위그노 학살(1572), 30년 전쟁(1618~1648)
Q4. KJV 유일주의에 대한 교수의 비판을 요약하시오.
