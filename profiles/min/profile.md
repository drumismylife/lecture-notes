# 목회학 — 노트 정리 프로필

## 과목 성격
실천신학. 목회자의 정체성·소명, 목회 리더십, 예배·설교·교육·심방·상담, 현대 목회 이슈.
이론보다 **원리 → 정의 → 적용 → 사례**의 흐름이 핵심. 목회 현장 적용 가능성을 중시.

## 노트 구조 (권장 섹션 순서)
1. **주제 개관** — 이번 주차 핵심 질문/주제.
2. **핵심 원리 / 정의** — 목회 개념의 정의를 박스로 명확히.
3. **전개** — 원리별 설명 + 성경적 근거(구절 인용).
4. **현장 적용** — 적용 포인트·체크리스트(실천 가능한 형태).
5. **사례 / 예화** — 교수가 든 예화·사례.
6. **시험 포인트** — 교수 강조·반복.
7. **출처·검증 요약**.

## 강조점 / 자주 나오는 것
- 목회자의 정체성·소명·자기관리·영성.
- 리더십(권위 vs 권력, 서번트 리더십).
- 현대인의 종교성향 변화와 교회의 대응, 예배·교육·소그룹.
- 정의(definition)와 분류를 시험에서 자주 물음 → "교수 강조" 배지.

## 표기 / 톤
- 따뜻하고 단정한 톤. 목회적 적용을 부드럽게.
- 성경 구절 인용 시 출처(책·장:절) 명기.

## 보충 검증 — 관련 스킬
- `sermon-bible-dictionary`: 인용 성경 개념·인물·용어의 정확성 교차검증. 보충은 "보충" 배지로 분리.
