# 신약성서 I — 노트 정리 프로필

## 과목 성격
신약 개론 + 공관복음·요한복음·사도행전 석의. 신구약 중간기 배경, 신약의 세계, 정경·본문비평,
각 복음서의 신학적 구조와 기독론, 편집비평적 관점. **본문 구조 분석**과 **신학 주제** 도출이 핵심.

## 노트 구조 (권장 섹션 순서)
1. **개관 / 배경** — 문헌·저자·연대·수신자·역사 배경.
2. **본문 구조** — 책/단락의 개요(아웃라인). 구조적 흐름을 도식으로.
3. **신학 주제 / 기독론** — 핵심 신학 주제 박스(예: 마가의 고난받는 종, 누가의 보편구원).
4. **편집비평 / 비교** — 공관복음 평행본문 비교, 자료·편집 관점.
5. **주요 본문 인용** — 핵심 구절(원문/번역) + 간단 석의. 성경 인용 박스.
6. **시험 포인트** — 교수 강조(구조·신학 주제·연대/저자 자주 출제).
7. **출처·검증 요약**.

## 강조점 / 자주 나오는 것
- 각 복음서의 **고유 신학·기독론**과 구조.
- 신약 27권 구조·정경 형성·본문비평·석의 방법.
- 공관복음 문제, 편집비평적 읽기.
- 연대·저자·수신자 등 개론 사실(시험 단골).

## 표기 / 톤
- 차분하고 학구적인 톤. 성경 인용은 책·장:절 명기, 인용 박스로 분리.
- 헬라어 원어가 나오면 음역+한글발음 병기(원어 표기는 헬라어 프로필 규약 준용).

## 보충 검증 — 관련 스킬
- `sermon-bible-dictionary`(인물·지명·개념), `sermon-history-culture-geo-context`(시대·문화 배경),
  `sermon-greek-grammar-machen`(원어 구문), `sermon-textual-criticism`(본문 이문) 으로 교차검증.
- 보충은 "보충" 배지로 강의 내용과 분리. 학계 주류 합의를 따른다.
