# 헬라어 II — 노트 정리 프로필

## 과목 성격
헬라어 I 후속 심화. 안호준·장석조 『언어학에 기초한 신약성경 헬라어 입문』 기반. **동사 체계 전반**과
**동사상(verbal aspect)** 이 핵심 축. 부정과거(아오리스트)·완료·미래, 단축/유음동사, 분사, 명령법,
남은 문법(접속사·관계대명사·가정법·부정사)까지. 헬라어 I → II 흐름은 사이트의 "1학기 총정리 →
헬라어 II 준비" 브릿지 자료와 연결.

## 노트 구조 (권장 섹션 순서)
1. **이번 차시 학습목표** — 실라버스 학습성과 기준.
2. **복습 연결** — 헬라어 I에서 이어지는 지점(특히 초반 복습 차시).
3. **문법 핵심** — 패러다임 표(동사 변화·분사·명령법) 중심. 헬라어 I 프로필의 표 규약 준용.
4. **동사상(aspect) 함의** — 이 시제/형태가 **본문 해석**에 갖는 의미(이 과목의 강조점).
5. **파싱 + 본문 적용** — 형태 분석 + 실제 신약 본문 해석 포인트(시험이 본문 해석 위주).
6. **어휘** — 심화 어휘.
7. **출처·검증 요약**.

## 표기 규약 (헬라어 I과 동일)
- **원어 4줄 표기**: 원문 / 음역 / 한글발음 / 뜻.
- 악센트·호흡부호·묵음 이오타 정확히. 한국 신학교 표준 문법 용어.

## 강조점 / 자주 나오는 것
- **동사상(verbal aspect)** — 교수가 명시적으로 강조. 완료/미완료/부정과거 상의 해석적 함의.
- 부정과거(아오리스트) 능·중·수동, 현재완료·과거완료, 미래시제.
- 단축동사·유음동사, 분사(현재·부정과거·완료·미래), 명령법.
- **본문 해석 위주 시험** → 변화표 암기 + 실제 본문 적용 둘 다.
- 헬라어 주기도문 암송(과제) → 주기도문 헬라어 텍스트·발음 정리 유용.

## 단어 파싱·표기 규칙
- **파싱 정확성 최우선**: 자막 스크립트의 헬라어가 부정확하더라도 앞뒤 문맥 + 교재·사전 검증을 통해
  **원래 단어 형태를 최대한 정확히 복원**하여 표기한다.
- 파싱된 단어에는 반드시 **발음을 함께 표기** (원어 4줄 표기 규약 적용).
- 파싱 항목(**7요소**, 교수 답안 표기법 준수): **원형(한글 음가) + 법·시제·태·인칭·수·(현저성)** —
  예: ἀκούσει → "아쿠오"의 직.미.능.3.단(0). **미래·부정과거의 현저성은 0.**
  (근거: 교수 카톡 공지 2026.7.3 백업 `Talk_2026.7.3 08:28-1.txt`, 7주차 강의)

## 검증 강도
- **ASR 보정: 최고 강도.** 원어·악센트·호흡부호·파싱 7요소는 발음만으로 절대 확정하지 말 것 —
  교재 캡처(위 "교재 캡처 이미지" 섹션)의 원어 표기를 항상 우선 근거로 삼는다. 캡처로 확정 안
  되면 Machen으로 보완하고, 그래도 안 풀리면 "표기 불확실"로 남긴다.
- **자료 의존도: 높음(PPT 대신 교재 캡처가 1차 자료).** 이 과목은 슬라이드가 아니라 교재
  캡처본이 원어 정확도의 기준 원본 — 패러다임 표·연습문제 원문은 녹취만으로 재구성하지 말고
  반드시 캡처와 셀 단위/문자 단위 대조. "강의추가"는 주로 본문 해석·동사상 설명 부연에서 발생.
